Modular Architecture

Engineered Without Compromise

Every component of XenRGB is built from scratch with clean abstractions, modular providers, and open protocols.

Native SignalRGB JS Engine

Runs community SignalRGB JavaScript device plugins directly in an embedded Google V8 engine (ClearScript). Full direct USB HID and memory-mapped IO without Electron or Chromium bloat.

OpenRGB & WLED Protocol Hub

Auto-downloads, launches, and synchronizes with OpenRGB server to control motherboards, RAM, and GPUs from ASUS, Gigabyte, and Corsair. Streams sub-millisecond UDP DRGB to WLED Wi-Fi strips.

2D Spatial Desktop Canvas

Place your devices on an intuitive visual grid matching your actual desk setup. Circular fan ring layouts automatically map ARGB headers, AIO water blocks, and case fans into beautiful concentric rings.

Roslyn Runtime C# Effects

Effects are simple, human-readable C# files (`effect.cs` + `manifest.json`). Hot-reload and compile them on the fly with Microsoft Roslyn compiler at near-instant native execution speed.

Hardware Watchdog Guard

Hardware keyboards (like HyperX Alloy Origins) revert to factory rainbow mode if they don't receive USB packets for 2–5 seconds. XenRGB emits intelligent heartbeat frames so your lighting never twitches or drops.

Good Night & Display Sleep

Automatically dims and blacks out all lights when screens sleep or lock. Good Night mode keeps the PC running 24/7 in total stealth darkness with zero animation thread CPU consumption (0.0%).

Write Custom Lighting in Seconds

No complex SDK toolchains or C++ rebuilds. Just drop a C# file into the effects/ directory and hit Reload.

effects/MyRainbowWave/effect.cs
using System;
using XenRGB.SDK;

public sealed class MyRainbowWaveEffect : EffectBase
{
    // Evaluated for each LED on the 2D spatial canvas
    public override RgbColor Evaluate(Point2D position, double time)
    {
        float speed = GetFloat("speed", 1.5f);
        float frequency = GetFloat("frequency", 8.0f);

        // Calculate smooth spatial phase from 2D coordinates
        float phase = position.X * frequency + (float)time * speed;
        float hue = (phase * 60f) % 360f;
        if (hue < 0) hue += 360f;

        return RgbColor.FromHsv(hue, 1.0f, 1.0f);
    }
}
